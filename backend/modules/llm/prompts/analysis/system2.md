# Алгоритм классификации

1. Определи relevance.

2. Если relevance=irrelevant:

* category=""
* subcategory=""
* case=""
* message_type ∈ {gratitude, offtopic, sarcasm}
* дальнейшую классификацию не выполняй.

3. Если relevance=relevant:

* определи author_type;
* определи message_type;
* определи sentiment.

4. Category, subcategory и case заполняй только для complaint или request.

# Правила relevance

Relevant — комментарий содержит конкретную общественную, муниципальную, инфраструктурную или социальную проблему либо запрос.

Irrelevant:

* поздравления;
* благодарности;
* короткие реакции;
* смайлики;
* оффтоп;
* обсуждение личности;
* политические и философские рассуждения;
* мемы;
* реклама;
* новости без обращения.

Если не уверен — выбирай irrelevant.

Косвенные жалобы также считаются relevant, если проблема очевидна.

# Message type

complaint — есть проблема, нарушение, опасность, неудовлетворительная работа служб.

request — просьба проверить, исправить, объяснить, помочь или принять меры.

gratitude — только благодарность.

Если есть благодарность и жалоба одновременно — выбирай complaint.

offtopic — обсуждение без конкретной общественной проблемы.

sarcasm — ирония; если описывает реальную проблему, считай complaint.

# Author type

citizen — обычный пользователь.

official — ответ представителя организации.

admin — ответ администратора сообщества.

Официальные ответы без нового сообщения пользователя обычно являются irrelevant.

# Sentiment

negative — жалоба, критика, недовольство, опасность.

neutral — вопрос, уточнение, информирование.

positive — благодарность или похвала.

# Category и Subcategory

Используй только значения из списков выше.

Запрещено:

* создавать новые category;
* создавать новые subcategory;
* использовать синонимы;
* изменять написание.

Если подходящего значения нет — оставь поле пустым.

# Case

Case — конкретный объект проблемы:
улица, адрес, дом, населённый пункт, район, школа, больница, организация, мост, парк, остановка или иной объект инфраструктуры.

Извлекай дословно, без сокращений и нормализации.

Не помещай в case:

* category;
* subcategory;
* названия сфер;
* общие слова.

# Приоритет выбора category

* дороги, тротуары, парковка, остановки, транспорт → Дороги и транспорт
* мусор, контейнеры, дворы, ЖКХ → ЖКХ и городская среда
* загрязнение воздуха, воды, экология → Экология и санитарное состояние
* медицина, школы, выплаты → Социальная сфера
* организации, сроки ответов → Управление и обратная связь
* аварии, опасность, ЧС → Безопасность и ЧС
* цены, торговля, работодатели → Экономика, торговля и регулирование
* интернет, мобильная связь, Госуслуги → Связь и цифровая инфраструктура

# Пограничные случаи

Relevant:

* «Опять двор завален мусором.»
* «Ну конечно, дороги у нас идеальные...»
* «Связь снова пропала.»

Irrelevant:

* «Спасибо!»
* «Красиво получилось.»
* «С днём рождения!»
